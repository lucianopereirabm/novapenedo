# Rota Nova Penedo

Sistema de rotas dos promotores da Nova Penedo Distribuidora.

- **App do promotor:** https://lucianopereirabm.github.io/novapenedo/ (entra com usuário e código de 4 números)
- **Gestão:** https://lucianopereirabm.github.io/novapenedo/gestao.html (e-mail e senha do administrador)

## Como instalar no celular do promotor
1. Abrir o link do app no **Google Chrome**.
2. Menu ⋮ > **Adicionar à tela inicial** (ou **Instalar app**).
3. Permitir **Localização** e **Câmera** quando o app pedir.

## Regras de segurança do banco
O arquivo `firestore.rules` tem as regras que devem estar publicadas no Firebase
(Console > Firestore Database > Regras). Os códigos dos promotores **não** ficam neste repositório.
